# Sonic-Unleashed-Randomizer
A stage randomizer mod for Sonic Unleashed Recompiled.

This randomizer shuffles stages throughout the game while preserving full game completion and progression.

---

## Features

* Randomized seeds
* Stage progression randomisation
* Boss battle support
* Seed generation and replay support
* Automatic archive repacking
* Generated spoiler log for every seed
* Day and Night stages can appear in unexpected locations
* Progression requirements preserved to prevent softlocks

---

## Requirements

* Sonic Unleashed Recompiled
* Sonic Unleashed DLC
* HedgeModManager
* Windows

---

## Installation

1. Download the randomizer release.

2. Extract the contents into your Sonic Unleashed Recompiled mods folder.

Example:

mods/SonicUnleashedRandomizer/

3. Enable the mod in HedgeModManager.

4. Run:

SonicUnleashedRandomizer.exe

5. Launch the game.

---

## Using Seeds

The randomizer generates a seed code for every run.

Example:

Seed Code: KA8uGSYCICMNGDcJBjMfEy80GxAEFCIWDjAsLQsFMgchAxEBChUnFx4rKTUdHDESDCUAJCoa

Reusing the same seed code will generate the same stage layout. You cannot create your own seeds. The seed codes can only be generated by the program.

---

## Randomizer Log

Each run creates:

randomizer_log.txt

This file contains:

* the generated seed
* all randomized stage mappings
* spoiler information for the run

---

## Known Notes

* The randomiser is designed around full game completion.
* EggmanLand is not included in randomisation logic.
* Medal progression remains mostly vanilla.
* Some progression logic is intentionally preserved for stability.
* Certain cutscenes may appear visually incorrect due to stage/map randomisation. This does not affect gameplay progression and the cutscene can still be watched normally.
* If the Egg Beetle boss battle is randomised, the pre-boss cutscene may behave unexpectedly. In most cases, losing a life after the cutscene plays will correctly reload the encounter. It is recommended to have more than one life before entering the fight.

## Troubleshooting

### HedgeArcPack.exe not found

Make sure:

HedgeArcPack.exe

is located beside:

SonicUnleashedRandomizer.exe


### Randomizer does not generate archives

Ensure the following folder exists:

#Application/

and is located beside the executable.
